ALIREZA DARIGH — PORTFOLIO WEBSITE
=================================
This is a responsive static portfolio website built from the supplied 78-page portfolio PDF.

HOW TO VIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Safari, Firefox or Edge.
3. Internet is only needed for the optional Google Fonts import; the site and gallery work offline.

HOW TO PUBLISH
Upload the contents of this folder (index.html, style.css, script.js and assets/) to the public_html folder of your hosting account. Do not upload only the ZIP file.

CUSTOMIZATION
- Edit text and contact details in index.html.
- Edit colors and layout in style.css. Main brand green: #075c3d.
- Portfolio images are in assets/ and the project list is embedded in index.html.
- All supplied portfolio sections are represented: Poster Design, Catalogue & Editorial, Logo & Branding, Book Cover Design, Social Media Design and UI/UX Design.

NOTES
The portfolio PDF's original artwork is presented as page images to preserve the supplied designs faithfully. Project titles are category-based rather than invented client/project names.
